# ClarityRec - Интегрируемая интеллектуальная система рекомендаций

Система состоит из трёх независимых модулей:
1. **Веб-приложение** (порт 3005) - основной сайт с карточками
2. **Модуль рекомендаций** (порт 3001) - независимый API для формирования рекомендаций
3. **Модуль объяснений** (порт 3002) - независимый API для визуализации объяснений

## Структура проекта

```
/workspace
├── package.json              # Корневой пакет для запуска всех модулей
├── web-app/                  # Веб-приложение (Vue.js + Node.js)
│   ├── package.json
│   ├── server.js
│   └── public/
│       └── index.html
├── recommendation-module/    # Модуль рекомендаций
│   ├── package.json
│   └── server.js
└── explanation-module/       # Модуль объяснений
    ├── package.json
    └── server.js
```

## Установка и запуск

### Вариант 1: Единый запуск всех модулей (рекомендуется)

```bash
cd /workspace
npm install
npm start
```

Это запустит все три сервера одновременно через `concurrently`.

### Вариант 2: Раздельный запуск в разных терминалах

**Терминал 1 - Модуль рекомендаций:**
```bash
cd /workspace/recommendation-module
npm install
npm start
```

**Терминал 2 - Модуль объяснений:**
```bash
cd /workspace/explanation-module
npm install
npm start
```

**Терминал 3 - Веб-приложение:**
```bash
cd /workspace/web-app
npm install
npm start
```

## Функционал

### Для администратора:
- Просмотр списка созданных пользователей
- Создание нового пользователя (ввод имени → автоматический переход к ленте пользователя)
- Переключение между пользователями

### Для пользователя:
- Лента карточек (30 карточек с 8 категориями)
- Если лайков < 5: показываются случайные карточки
- Если лайков ≥ 5: показываются рекомендованные карточки (отсортированные по весу рекомендации)
- Кнопка "Лайк" на каждой карточке
- Ссылка на личный кабинет с объяснением рекомендаций

### Личный кабинет:
- Если лайков < 5: заглушка с сообщением о необходимости лайков
- Если лайков ≥ 5: визуализация объяснений с:
  - Категорией рекомендации
  - Весом рекомендации
  - Триггером (событием)
  - Текстовым объяснением

## API модулей

### Модуль рекомендаций (порт 3001)

**POST /api/events** - Отправка события (лайка)
```json
{
  "userId": "user_123",
  "eventType": "like",
  "itemId": "1",
  "itemCategory": "Технологии"
}
```

**GET /api/recommendations/:userId** - Получение рекомендаций пользователя

**GET /api/user-data/:userId** - Проверка существования пользователя

### Модуль объяснений (порт 3002)

**POST /api/generate-explanation** - Генерация объяснений
```json
{
  "userId": "user_123",
  "recommendations": [
    {"category": "Технологии", "weight": 3, "trigger": "like"}
  ]
}
```

**GET /api/explanation/:userId** - Получение объяснений пользователя

## Принцип работы

1. Пользователь лайкает карточки на веб-сайте
2. Веб-приложение отправляет события в модуль рекомендаций через его API
3. После 5 лайков модуль рекомендаций формирует рекомендации на основе категорий
4. Веб-приложение получает рекомендации и начинает показывать рекомендованные карточки
5. Веб-приложение отправляет данные рекомендаций в модуль объяснений
6. Модуль объяснений генерирует текстовые объяснения и возвращает их
7. Объяснения отображаются в личном кабинете пользователя

## Независимость модулей

Оба модуля (рекомендаций и объяснений) являются независимыми и могут быть интегрированы в любые другие системы через их REST API. Главное свойство проекта — модули не связаны жёстко с веб-приложением и могут работать с любыми другими системами, которые обращаются к их API.

## Технологии

- **Frontend:** Vue.js 3 (через CDN)
- **Backend:** Node.js + Express
- **API:** REST API с CORS поддержкой
